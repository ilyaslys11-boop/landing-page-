# Images

Place your product photos in this folder with the following filenames:

| File | Used for |
|------|----------|
| `hero-kit.png`   | Hero section — the 5-piece kit photo |
| `before-1.jpg` / `after-1.jpg` | First before/after transformation |
| `before-2.jpg` / `after-2.jpg` | Second before/after transformation |
| `before-3.jpg` / `after-3.jpg` | Third before/after transformation |

If an image is missing, the page falls back to a styled placeholder automatically.

Recommended dimensions:
- Hero kit: **1000×1000 px**, transparent PNG
- Before/After: **600×340 px** each (landscape)
